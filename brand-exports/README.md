# Brand exports

PNG versions of the logo for services that cannot use SVG (Kit, email, profile pictures).
Generated from `public/logo/`.

| File | Use |
|---|---|
| `kit-email-logo-1200.png` | Kit: Settings → Brand → logo (email header). Transparent background, 1200 px wide. |
| `latf-avatar-512.png` | Square avatar: Kit favicon, Google account photo, social profile pictures. |
